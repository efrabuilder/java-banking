# 🏦 Banking System — Java

Simple console banking system built in Java with account management, deposits, withdrawals, transfers and transaction history.

Built by **Efraín Rojas Artavia**

---

## Features
- ✅ Create and manage **bank accounts**
- ✅ **Deposit** and **withdraw** funds
- ✅ **Transfer** between accounts
- ✅ View full **transaction history**
- ✅ Session-based **login system**
- ✅ Pre-loaded sample accounts for testing

## Quick Start
```bash
javac BankingSystem.java
java BankingSystem
```
Requires **Java 17+**
